Цель
Получить пароль для следующего уровня (bandit15), отправив пароль текущего пользователя (bandit14) на порт 30000 локального хоста.
Решение
1. Поиск файла с паролем текущего уровня
Пароль пользователя bandit14 хранится в файловой системе. Для его нахождения использована команда find, осуществляющая поиск по имени файла в директории /etc:

find /etc -name "bandit14"


2. Проверка доступности порта 30000
Перед отправкой данных необходимо убедиться, что целевой порт открыт и принимает соединения. Использована утилита nmap:

nmap -p 30000 localhost

3. Отправка пароля на порт 30000
Поскольку в задаче не указано требование шифрования, отправка выполнена через netcat (nc) — утилиту для передачи данных по TCP:

cat /etc/bandit_pass/bandit14 | nc localhost 30000

Что происходит:
•	cat читает пароль из файла и передаёт его в nc.
•	nc подключается к localhost:30000 и отправляет полученную строку.
•	Сервер на порту 30000 принимает пароль и в ответ выводит пароль для следующего уровня (bandit15).
Результат: получен пароль уровня bandit15, который используется для дальнейшего прохождения игры.
