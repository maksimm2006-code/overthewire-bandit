Цель задачи
Получить пароль для следующего уровня, отправив пароль текущего пользователя (bandit15) на порт 30001 локального хоста. Соединение должно быть защищено протоколом SSL/TLS.
Решение
1. Поиск файла с паролем текущего уровня
Перед отправкой данных необходимо было найти, где хранится пароль пользователя bandit15. Для этого использована команда find, осуществляющая поиск по имени файла в системной директории /etc, где в игре Bandit традиционно располагаются пароли уровней.

2. Проверка доступности порта с помощью Nmap
Перед отправкой данных необходимо убедиться, что целевой порт открыт и принимает соединения. Для этого использовалась утилита nmap и чтобы убедиться что порт требует шифрованное соединение, применяется Nmap-скрипт ssl-cert:
nmap –script ssl-cerl -p 30001 localhost
Результат:
Порт 30001 отмечен как open (открыт). Это подтверждает, что на порту работает сервер, готовый к приёму SSL-соединений.		

3. Отправка пароля через openssl s_client
Поскольку сервер требует шифрование, обычный netcat или telnet не подходят. Использована команда openssl s_client:
openssl s_client -connect localhost:30001

После установления защищённого соединения вручную введён пароль текущего уровня (из файла /etc/bandit_pass/bandit15). Сервер ответил строкой — паролем для следующего уровня.

4. Автоматизация с помощью скрипта
Для ускорения решения задачи (особенно если бы порт был неизвестен или требовалось многократное подключение) был разработан скрипт, который:
•	принимает порт, целевой хост и пароль;
•	проверяет открытость порта через nmap;
•	при успехе отправляет пароль через openssl s_client и остаётся в интерактивном режиме.
